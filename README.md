# Computer Network

컴퓨터 네트워크 학습 내용을 정리하고 기록하는 개인 저장소입니다.

## 📚 Contents

네트워크의 주요 개념과 프로토콜을 주제별로 정리합니다.

| Directory | Description |
|---|---|
| `01_Network_Basics` | 네트워크 기초 개념 |
| `02_Data_Link_Layer` | 데이터 링크 계층 |
| `03_Network_Layer` | 네트워크 계층 |
| `04_Transport_Layer` | 전송 계층 |
| `05_Application_Layer` | 응용 계층 |

## 📝 Documentation Rules

- 각 디렉터리는 주제별로 구분합니다.
- 각 디렉터리의 README.md에는 해당 주제에 대한 설명을 작성합니다.
- 개별 파일에는 세부적인 학습 내용을 기록합니다.
- 필요한 경우 예제 코드와 참고 자료를 함께 관리합니다.

## 🎯 Goal

컴퓨터 네트워크의 핵심 개념을 체계적으로 정리하고, 학습 과정에서 습득한 지식을 지속적으로 축적합니다.
